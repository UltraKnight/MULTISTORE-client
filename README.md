# 🛒 Marketplace Store Simulation

This is a full-featured store simulation web application where users can **buy and sell products** with each other. It includes a modern UI, integrated payments via **Stripe**, and responsive design using **Bootstrap** and **SASS**.

---

## 🚀 Overview

The project started as a JavaScript-based app built with **Create React App (CRA)** and was later migrated to **TypeScript** and bundled using **Vite** for improved performance and DX (Developer Experience). It was first developed as a project of my Web Development Bootcamp in Ironhack Lisbon.

⚠️ Be aware that this project is not regularly updated and may break due to the fast-paced evolution of the programming ecosystem.

---

## 🛠️ Tech Stack

- **Frontend Framework**: React (originally CRA + JS, now Vite + TS)
- **Styling**: SASS, Bootstrap 5
- **Icons**: React Icons
- **Payments**: Stripe API
- **Deployment**: Netlify

---

## ✨ Features

- User registration and authentication powered by **Passport.js**
- Browse products listed by other users
- Create, update, and delete product listings
- Secure payments with Stripe
- Responsive and accessible UI
- Dashboard to manage purchases and sales
- Real-time UI interactions with modern React features (Hooks, Context API, etc.)

## 📦 Installation

1. **Clone the repo:**

  ```bash
    git clone https://github.com/UltraKnight/MULTISTORE-client.git
    cd MULTISTORE-client
  ```

2. **Install dependencies:**
  
    Run `npm install`

3. Clone and run the Backend:
    
    https://github.com/UltraKnight/MULTISTORE

4. **Setup environment variables**
  
    Create a .env file in the root and use .env.example file as a guide

5. Run the dev server
    
    Run `npm start`
